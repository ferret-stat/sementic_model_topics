# Semantic Model & Topic Analysis (`sementic_model_topics`)

Проект предназначен для предварительной обработки текстовых данных, анализа тональности (**Sentiment Analysis**) и тематического моделирования (**Topic Modeling**) с использованием алгоритма K-Means и методов машинного обучения.

## 📁 Структура проекта

```text
sementic_model_topics-main/
├── data/
│   ├── datasets_example.csv       # Пример датасета с текстами и тональностью
│   └── stopswords_example.txt     # Список стоп-слов
├── notebooks/
│   ├── datasets_metrics.ipynb     # Исследование датасетов и метрик
│   ├── kmeans_optimized.ipynb     # Оптимизированное тематическое моделирование
│   ├── kmeans_optimized_v2.ipynb  # Дополнительные эксперименты с K-Means
│   └── sentiment_model.ipynb      # Эксперименты с моделью анализа тональности
├── src/
│   ├── __init__.py                # Инициализация Python-пакета
│   ├── preprocessing.py           # Предобработка текста
│   ├── sentiment_model.py         # Модуль анализа тональности
│   └── topic_model.py             # Модуль тематического моделирования
├── .gitignore                     # Исключения Git
└── README.md                      # Документация проекта
```

## ⚙️ Основной функционал

### 1. Предобработка текста

Модуль `src/preprocessing.py` предназначен для подготовки текстовых данных к дальнейшему анализу.

Основные задачи:

- Очистка текста от специальных символов и шума.
- Удаление стоп-слов с использованием списка `data/stopswords_example.txt`.
- Подготовка текстов к векторизации и машинному обучению.

### 2. Анализ тональности (Sentiment Analysis)

Модуль `src/sentiment_model.py` предназначен для классификации текстов по эмоциональной окраске.

Основные возможности:

- Классификация текстов по тональности: позитивная, негативная и нейтральная.
- Обучение и тестирование модели.
- Проведение экспериментов в ноутбуке `notebooks/sentiment_model.ipynb`.

### 3. Тематическое моделирование (Topic Modeling)

Модуль `src/topic_model.py` реализует тематическое моделирование на основе алгоритма K-Means.

Основные задачи:

- Кластеризация текстовых документов.
- Подбор оптимального количества кластеров.
- Оценка качества кластеризации.
- Извлечение ключевых тем из полученных кластеров.

Эксперименты и оптимизация представлены в ноутбуках `notebooks/kmeans_optimized.ipynb` и `notebooks/kmeans_optimized_v2.ipynb`.

### Использование модулей Python

Функциональность проекта можно импортировать в собственные скрипты.

Пример использования модуля предобработки:

```python
from src.preprocessing import preprocess_text
from src.sentiment_model import SentimentModel
from src.topic_model import TopicModel

# Пример исходного текста
raw_text = "Пример текста для анализа и кластеризации!"

# Предобработка текста
clean_text = preprocess_text(raw_text)

print(f"Очищенный текст: {clean_text}")
```

> **Примечание:** пример предполагает, что функция `preprocess_text` и классы `SentimentModel` и `TopicModel` доступны под указанными именами. Проверьте их фактические определения в соответствующих файлах `src/`.

## ⚠️ Ограничения

- Результаты тематического моделирования зависят от качества предобработки текста, способа векторизации и выбранного количества кластеров.
- Названия тем необходимо интерпретировать на основе наиболее характерных слов и документов каждого кластера.
- Качество классификации тональности следует оценивать на отложенной выборке с помощью подходящих метрик, например precision, recall и F1-score.
- Для воспроизводимого запуска рекомендуется зафиксировать версии зависимостей в `requirements.txt`.
